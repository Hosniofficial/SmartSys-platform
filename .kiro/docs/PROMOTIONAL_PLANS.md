# الخطط الترويجية - Promotional Plans

## نظرة عامة

يمكن إنشاء خطط ترويجية خاصة للمستخدمين الجدد أو للعروض المحدودة الوقت.

## الخطط المتاحة

### 1. Trial (14 أيام)
- **الكود:** `trial`
- **المدة:** 14 يوم
- **السعر:** مجاني (EGP 0.00)
- **الحالة:** محمي من التعديل ❌
- **الاستخدام:** الخطة الافتراضية للمستخدمين الجدد

### 2. Promotional 3 Months (3 أشهر مجانية) ✨ جديد
- **الكود:** `promo_3months`
- **المدة:** 90 يوم
- **السعر:** مجاني (EGP 0.00)
- **الحالة:** قابلة للتفعيل للعملاء المميزين
- **الاستخدام:** عروض ترويجية، عملاء جدد، عروض خاصة

### 3. Monthly
- **الكود:** `monthly`
- **المدة:** 29-30 يوم
- **السعر:** 250 EGP
- **الحالة:** قابلة للتحديث ✅

### 4. Yearly
- **الكود:** `yearly`
- **المدة:** 364 يوم
- **السعر:** 2,499 EGP
- **الحالة:** قابلة للتحديث ✅

---

## كيفية ربط خطة ترويجية لمستخدم جديد

### من الواجهة الأمامية (Admin Panel):
1. اذهب إلى **الاشتراكات** (Subscriptions)
2. ابحث عن المستخدم الجديد
3. اضغط على **تفعيل الاشتراك** (Activate)
4. اختر الخطة المطلوبة من القائمة:
   - `promo_3months` - للعرض الترويجي (3 أشهر مجاني)
   - `trial` - للتجربة (14 يوم)

### من API مباشرة:
```bash
POST /api/v1/admin/subscriptions/{id}/activate
Content-Type: application/json

{
  "plan": "promo_3months"
}
```

---

## إنشاء خطط ترويجية جديدة

### الخطوات:
1. اذهب إلى صفحة **إدارة الخطط** (Plans Management)
2. اضغط على زر **إضافة خطة جديدة**
3. املأ البيانات:
   - **كود الخطة:** `promo_[name]` (مثال: `promo_summer`, `promo_ramadan`)
   - **اسم الباقة:** اسم واضح ومميز
   - **السعر:** 0.00 إذا كانت مجانية
   - **العملة:** اختر من القائمة
   - **الدورة:** عدد الأيام (مثال: 180 للـ 6 شهور)
   - **الحالة:** نشط ✓

4. اضغط **إضافة الخطة**

## ملاحظات الأمان

### ✅ محمي من التعديل:
- خطة **Trial** محمية من التعديل في الواجهة الأمامية والخلفية
- هذا يمنع أي استغلال أو تعديل عشوائي

### ✅ الخطط الأخرى قابلة للتعديل:
- يمكن تعديل `monthly` و `yearly` و الخطط الترويجية الأخرى
- التعديلات تنطبق على الاشتراكات الجديدة فقط
- الاشتراكات الموجودة لا تتأثر

## أمثلة استخدام

### مثال 1: عرض ترويجي للعملاء الجدد (3 أشهر مجانية)
```
1. أضفت خطة جديدة: `promo_opening`
2. المدة: 90 يوم
3. السعر: 0.00 EGP
4. الاستخدام: 3 أشهر مجاني عند التسجيل الجديد
```

### مثال 2: عرض محدود الوقت (رمضان)
```
1. أضفت خطة جديدة: `promo_ramadan`
2. المدة: 30 يوم
3. السعر: 100 EGP (بدلاً من 250)
4. الاستخدام: عرض خاص خلال شهر رمضان
```

### مثال 3: عرض خاص للعملاء المميزين (سنة مجانية)
```
1. أضفت خطة جديدة: `promo_vip`
2. المدة: 365 يوم
3. السعر: 0.00 EGP
4. الاستخدام: برنامج ولاء للعملاء المميزين
```
